# 📘 Excel Workbook – Functions, Formatting & Pivot Reporting

This Excel workbook provides a set of **practical exercises** focused on essential spreadsheet skills used in data analysis and reporting.  
It includes core formulas, lookup operations, data formatting, and Pivot Table/Chart practice.

---

## 📌 Contents

### **1. Core Excel Functions**
Hands-on exercises covering fundamental analytical formulas:

- **SUM** – Add numeric ranges  
- **AVERAGE** – Calculate mean values  
- **SUMIF** – Conditional summation  
- **AVERAGEIF** – Conditional averages  
- **VLOOKUP** – Lookup values from reference tables  

Each sheet includes sample data and guided practice.

---

### **2. Formatting & Presentation**
Techniques to make data clean and readable:

- Number & currency formatting  
- Cell styling and alignment  
- Conditional formatting  
- Professional spreadsheet layout  

---

### **3. Pivot Tables**
Practice building Pivot Tables for business reporting:

- Aggregating values  
- Grouping fields  
- Filtering & sorting  
- Summaries for analysis  

---

### **4. Pivot Charts**
Visualizing Pivot Table output with:

- Column & bar charts  
- Line charts  
- Interactive filtering  

---

## 🎯 Purpose

This workbook is designed to strengthen **Excel fundamentals** for learners and entry-level data roles, including:

- Data Technician  
- Data Analyst  
- Business Intelligence support  
- Administrative reporting  

It is suitable for independent practice or interview preparation.
